# 互斥锁

​	加锁的本质是对资源加锁，因此我们一定能从加锁的代码中找到被锁的资源。

​	Java提供了`synchronized`来加锁，它可以修饰普通方法，静态方法，或者代码块

```java
class X {
  // 修饰非静态方法
  synchronized void foo() {
    // 临界区
  }
  
  // 修饰静态方法
  synchronized static void bar() {
    // 临界区
  }
  
  // 修饰代码块
  Object obj = new Object()；
  void baz() {
    synchronized(obj) {
      // 临界区
    }
  }
}  
```

- 修饰非静态方法时，上锁的资源是该对象本身（也就是`this`）；
- 修饰静态方法时，上锁的资源是该类（X.class）；
- 修饰代码快时，需要手动指定上锁的资源；



​	锁与资源是1:N的关系，即可以用一把锁锁的，但是不能用多把锁锁定同一个资源。
