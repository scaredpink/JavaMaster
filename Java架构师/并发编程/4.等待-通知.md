常规的破坏占有等待是我们让cpu空转，等到资源都获取到了就开始run

这种显然是浪费了cpu的运转，因为一旦到这个线程执行它就会空转一会

更好的方案是通知等待机制

1.当线程发现自己申请的资源不满足，阻塞自己，进入等待状态；

2.等到资源满足时，唤醒线程





wait() notify() notifyAll()关键字

wait()关键字，当线程使用synchroized获得资源时，如果发现条件不满足，则线程会释放自己的资源（互斥锁）并进入等待队列

notify()关键字，当线程使用synchronized获取资源并完成任务后，释放资源（互斥锁），并唤醒等待队列的线程



注意，两者都是Object类的方法，并且是native方法

他们需要在synchronized关键字内使用（获取到互斥锁时使用）



notifyAll更常用





另外，notify()表示的是有互斥锁释放过，不代表线程一定能拿到互斥锁，因此我们通常使用

```java
while(条件不满足) {
  	wait();
}
```

来做







```java
    synchronized void apply(Object from, Object to) {
        while (als.contains(from) || als.contains(to)) {
            try {
                wait();
            } catch (Exception e) {
            }
        }
        als.add(from);
        als.add(to);
    }

    synchronized void free(Object from, Object to) {
        als.remove(from);
        als.remove(to);
        notifyAll();
    }
```
