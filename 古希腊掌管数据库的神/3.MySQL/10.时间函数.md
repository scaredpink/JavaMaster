# 获取日期时间数据中部分信息

```sql
extract(type from xxx)
```

其中type表示获取的指定的部分，可以是小时（hour），年份（YEAR），月份（MONTH）



或者可以直接用对应的函数

例如 HOUR() 

- YEAR（date）：获取date中的年。
- MONTH（date）：获取date中的月。
- DAY（date）：获取date中的日。
- HOUR（date）：获取date中的小时。
- MINUTE（date）：获取date中的分。
- SECOND（date）：获取date中的秒。





## 计算日期时间的函数

- DATE_ADD（date, INTERVAL 表达式 type）：表示计算从时间点“date”开始，向前或者向后一段时间间隔的时间。“表达式”的值为时间间隔数，正数表示向后，负数表示向前，“type”表示时间间隔的单位（比如年、月、日等）。
- LAST_DAY（date）：表示获取日期时间“date”所在月份的最后一天的日期。



如何获取一年前当前月份的开始和结束时间



获取去年的这个月的时间

```sql
select DATE_ADD('2025-06-12', INTERVAL -1 year);
```

获取去年这个月的上个月

```sql
select DATE_ADD(DATE_ADD('2025-06-12', INTERVAL -1 year), interval -1 month);
```

获取去年这个月的上个月的最后一天

```sql
select LAST_DAY(DATE_ADD(DATE_ADD('2025-06-12', INTERVAL -1 year), interval -1 month));
```

获取去年这个月的上个月的最后一天的后一天

也就是去年这个月的第一天

```sql
select date_add(LAST_DAY(DATE_ADD(DATE_ADD('2025-06-12', INTERVAL -1 year), interval -1 month)), interval 1 day );
```



类似的道理

去年这个月的最后一天

```sql
select date_add(last_day(date_add('2025-06-12', interval -1 year)), interval 1 day );
```





- ADDDATE()：跟DATE_ADD()用法一致；
- DATE_SUB()，SUBDATE()：与DATE_ADD()用法类似，方向相反，执行日期的减操作。





## 其他

- CURDATE（）：获取当前的日期。日期格式为“YYYY-MM-DD”，也就是年月日的格式。
- DAYOFWEEK（date）：获取日期“date”是周几。1表示周日，2表示周一，以此类推，直到7表示周六。



位了让DAYOFWEEK结果复合国内的逻辑，可以用case修改一下

```sql
select case dayofweek(curdate()) - 1 when 0 then 7 else dayofweek(curdate()) - 1 END;
```





- **DATE_FORMAT()，它表示将日期时间“date”按照指定格式显示**。

%T表示24小时制度

```sql
SELECT DATE_FORMAT(CURRENT_TIME, '%T');
```

%r表示12小时制度





- DATEDIFF（date1,date2），表示日期“date1”与日期“date2”之间差几天。

```
SELECT DATEDIFF(CURRENT_DATE, '2024-01-01');
```
