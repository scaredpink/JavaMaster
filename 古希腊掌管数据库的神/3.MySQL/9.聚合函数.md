# 聚合函数

## SUM()

sum用来获取指定字段值求和

```sql
select LEFT(b.transdate, 10), c.goodsname, sum(a.quantity), sum(a.salesvalue)
from transactiondetails as a
    left join transactionhead as b on a.transactionid = b.transactionid
    left join goodsmaster as c on a.itemnumber = c.itemnumber
group by LEFT(b.transdate, 10), c.goodsname;
```



`LEFT(str, n)`：返回str的左边n个字符，DATETIME类型包含时分秒，所以如果想要按照日期分组，需要截取左边的10个字符







AVG求平均

MAX求最大值

MIN求最小值





## COUNT()函数

count函数用来统计记录条数

- COUNT（*）：统计一共有多少条记录；
- COUNT（字段）：统计有多少个不为空的字段值。

































































## 附录

```sql
create table transactiondetails (
    transactionid int,
    itemnumber int,
    quantity int,
    price decimal(10,2),
    salesvalue decimal(10,2)
);

create table transactionhead(
    transactionid int primary key ,
    transactionno varchar(128),
    cashierid int,
    memberid int,
    operatorid int,
    transdate datetime
);

drop table if exists goodsmaster;
create table goodsmaster(
    itemnumber int primary key ,
    barcode varchar(128),
    goodsname varchar(128),
    specification varchar(128),
    unit varchar(128),
    salesprice decimal(10,2)
)
```
